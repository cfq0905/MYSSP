    Technical overview

    Low-resource Malay emotion text is scarce and imbalanced. This project builds affect-aligned Malay data with EAT, then trains MEPC for cross-lingual emotion classification across English, Malay, and Chinese.

    EAT

    Qwen2.5 is conditioned on ground-truth emotion labels to translate GoEmotions into Malay (GoMS), preserving tone better than translate-only prompting (TOGA).

    MEPC

    XLM-RoBERTa-base → dropout 0.25 → 256-d projection. Six-way episodic multiprototype classification with weighted supervised contrastive loss; Malay-heavy queries (0.80).

    Data

    GoEmotions (EN), GoMS (MS), MYBully (MS), CMED (ZH). Fear dropped for sparsity. Malay training mix: GoMS 75% · MYBully 25%. Seed 42.

    Reported results

    MEPC–EAT on GoMS + MYBully (n = 1,172): BalAcc 0.5983, Macro-F1 0.5829, Weighted-F1 0.6095. EAT-7B downstream BalAcc (7-class) 0.7138.

    Task
    Single-label emotion classification
    Labels
    anger · disgust · joy · neutral · sadness · surprise
    Encoder
    xlm-roberta-base
    Training
    Episodic 10–15 shot · SupCon · logit calibration
